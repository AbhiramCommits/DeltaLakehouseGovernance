# DeltaLakehouseGovernance

A local-but-real Databricks-style medallion lakehouse on Delta Lake with governance, data quality and observability, incremental streaming ingest, and a governed agentic analytics service over the gold marts. Built end to end with PySpark 3.5 + delta-spark, Spark SQL, Structured Streaming, FastAPI and pytest; everything runs locally with no cloud account required. Full documentation and measured results are added in Step 7.
